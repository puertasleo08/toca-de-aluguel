# Ferramentas de referência visual e prototipação

Use estas ferramentas quando faltar uma direção visual concreta para o projeto — antes de codificar com o default do framework, calibre um estilo específico.

## Geração e prototipação de UI (produzem código ou protótipo navegável)

- **v0** — https://v0.app — gera componentes/telas em React + Tailwind + shadcn/ui a partir de prompt; bom ponto de partida para estrutura, mas ainda precisa passar pelo checklist da seção 4 do guia principal (síndrome do template genérico não desaparece sozinha).
- **Google Stitch** — https://stitch.withgoogle.com — geração de UI a partir de prompt/imagem, com foco em fluxos de design mais do que em código final.
- **Subframe** — https://subframe.com — design + geração de código de componentes com mais controle manual sobre o resultado do que geradores puramente por prompt.
- **Antigravity** — https://antigravity.google — ambiente de desenvolvimento agER com foco em produtividade de codificação assistida por IA.

## Bancos de componentes e efeitos prontos

- **Aceternity UI** — https://ui.aceternity.com — catálogo navegável dos efeitos 3D/spotlight/background mencionados na seção de bibliotecas.
- **21st.dev** — https://21st.dev — marketplace de componentes React/Tailwind feitos pela comunidade, bom para buscar um padrão específico (ex.: "pricing table", "sidebar") já testado visualmente.

## Bancos de referência visual (sem código, só inspiração)

- **Dribbble** — https://dribbble.com — portfólio de designers, útil para explorar direção de estilo antes de definir a paleta/tipografia do projeto.
- **Pinterest** — https://pinterest.com — bom para moodboards amplos e composição visual geral (não específico de UI).
- **Mobbin** — https://mobbin.com — biblioteca de screenshots reais de apps e produtos em produção; a melhor fonte para ver como produtos de ponta resolvem um fluxo específico (onboarding, checkout, configurações) sem depender de mockups conceituais.

## Como usar essas ferramentas sem cair no genérico

1. Comece por Mobbin ou Dribbble para calibrar uma direção de estilo concreta (não "moderno e limpo" — um produto/marca de referência real).
2. Se for gerar com IA (v0, Stitch, Subframe), leve essa referência no prompt em vez de pedir algo genérico.
3. Depois de gerar, sempre passe pelo checklist da seção 4 do guia principal — geradores de UI reproduzem exatamente os tiques da "síndrome do template genérico" quando usados sem referência específica.
